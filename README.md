# PAPAlarm 🌷
Alarm rutinitas Android: suara sendiri/audio HP + harus ambil foto baru untuk mematikan alarm.

## Fitur v1
- Alarm sekali atau hari pilihan
- Kategori: Self Care, Ibadah, Kesehatan, Rumah, Belajar, Hewan, Lainnya
- Rekam suara sendiri
- Pilih audio dari HP
- Getar
- Full-screen alarm / notification
- Kamera baru sebagai syarat mematikan alarm
- Foto bukti tidak disimpan ke galeri
- Re-schedule setelah HP restart

## Build di GitHub
Upload isi folder ini ke repository GitHub. GitHub Actions `Build PAPAlarm APK` akan membuat APK debug sebagai artifact.

## Catatan Android
Saat pertama dibuka, izinkan notifikasi dan akses "Alarms & reminders" agar alarm lebih tepat waktu.
